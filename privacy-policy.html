🔒 隐私政策

生效日期：2026 年 4 月 29 日 | 最后更新时间：2026 年 4 月 29 日

欢迎使用智享畅学平台（以下简称"本软件"）。我们非常重视您的隐私保护，制定本隐私政策旨在向您说明我们如何收集、使用、存储和保护您的个人信息。

🛡️ 重要承诺：
本软件所有数据均存储在您设备的本地，绝不上传到任何云端服务器，不存在网络传输和数据泄露风险，您的信息安全完全由您掌控。

一、数据收集范围

1.1 我们收集的数据类型

为了提供基本的考试和 AI 辅助功能，本软件会在您的设备上本地收集以下必要数据：

数据类型 收集目的 是否上传云端
用户账号信息 用于身份验证和用户识别 ❌ 否（仅本地存储）
考试内容及答案 用于在线考试和成绩记录 ❌ 否（仅本地存储）
学习记录和进度 用于个人学习分析 ❌ 否（仅本地存储）
社区发帖内容 用于社区论坛交流 ❌ 否（仅本地存储）
AI 对话历史 用于智能答疑和辅助学习 ⚠️ 仅通过官方 API 加密传输至 AI 服务商
设备标识符 用于防作弊检测（如切屏次数） ❌ 否（仅本地统计）

1.2 我们不收集的数据

请注意：
本软件不会收集以下敏感信息：
• 银行卡号、密码等财务信息
• 通讯录、短信、通话记录等个人隐私
• 地理位置信息
• 摄像头、麦克风等权限访问
• 任何与考试和学习无关的用户数据

二、数据使用目的

我们仅在以下目的范围内使用您的本地数据：

  1. 题库管理：方便教师和学生管理题目资源，包括题目的导入、导出、分类和检索。
  2. 学习分析与统计：基于本地数据生成学习进度报表、成绩统计图表，帮助用户了解学习情况。
  3. AI 智能答疑：通过讯飞星火（Spark）和 DeepSeek 大模型 API 提供智能答疑、题目解析和学习建议。
  4. 社区互动：为用户提供论坛交流空间，包括发帖、评论、收藏等功能，促进学习和经验分享。
  5. 防作弊检测：在考试过程中监测学生的屏幕切换行为，确保考试的公平性。
  6. 无障碍辅助：为有需要的用户提供语音输入、数学公式键盘等特殊功能支持。

三、数据存储方式（核心安全保障）

🏠 本地存储，绝对安全

  • 存储位置：所有用户数据（包括账号信息、考试内容、学习记录、社区帖子等）均存储在您设备的本地存储空间中。
  • 不联网同步：本软件不会产生任何云端同步操作，您的数据永远不会被上传到其他服务器。
  • 无第三方访问：除了必要的 AI 接口调用外，没有任何第三方可以访问您的本地数据。
  • 数据归属权：所有数据的所有权和使用权完全归您本人所有。

3.1 数据库采用 MySQL 8.0

我们使用业界标准的关系型数据库 MySQL 8.0 进行数据管理：

  • ✅ 开源免费，安全可靠
  • ✅ 数据加密存储，防止未授权访问
  • ✅ 支持事务处理，保证数据完整性
  • ✅ 本地部署，数据不出设备

3.2 加密措施

  • 密码加密：用户密码采用 SHA-256 哈希算法加密存储，即使数据库被非法访问也无法还原原始密码。
  • JWT Token：使用 JSON Web Token 进行用户身份验证，Token 有效期短且具有签名验证机制。
  • HTTPS 加密传输：AI 接口调用采用 HTTPS 协议加密传输，防止中间人攻击。

四、用户权利

根据《中华人民共和国网络安全法》和《个人信息保护法》，您享有以下权利：

  1. 查阅权：您可以随时查看您在设备上存储的所有个人数据和考试记录。
  2. 修改权：您可以修改自己的账号信息、密码、个人资料等内容。
  3. 删除权：您可以随时删除个人的考试记录、社区帖子、聊天记录等数据。
  4. 注销账号：您可以申请注销账号，注销后您的本地数据将被永久删除。
  5. 导出数据：您可以将考试题库、学习记录等数据导出为 Excel 或 JSON 格式，便于备份和迁移。

六、数据安全措施

🔐 多层次安全防护体系

我们采用以下技术和管理措施保护您的数据安全：

6.1 技术措施

  • 题库管理：采用 MySQL 本地数据库，数据完全存储在设备上，从源头上杜绝数据泄露风险。
  • 权限控制：基于 Spring Security + JWT 实现细粒度的权限控制，不同角色（学生、教师、管理员）只能访问其权限范围内的数据。
  • 输入验证：对所有用户输入进行严格校验，防止 SQL 注入、XSS 攻击等常见 web 攻击。
  • 日志审计：记录关键操作日志，便于追踪异常行为和进行安全审计。
  • 定期更新：及时更新依赖组件和安全补丁，防范已知漏洞。

6.2 管理措施

  • 最小化原则：只收集实现功能所必需的最少数据。
  • 数据隔离：不同用户之间的数据完全隔离，互不可见。
  • 责任明确：指定专人负责数据安全管理和应急响应。
